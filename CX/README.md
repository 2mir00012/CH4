# 분노의 질주: 원화 채굴

차량을 운전하며 원화와 속도 아이템을 모으고, 상대 차량을 공격해 제한 시간 안에 가장 많은 원화를 획득하는 멀티플레이 게임입니다. 석양이 지는 채석장을 무대로 차량 전투와 경기 결과를 구현했습니다.

## 개발 환경

- Unreal Engine 5.6.1
- C++ / Blueprint
- Visual Studio 2022
- 주요 엔진 플러그인: Chaos Vehicles, Raw Input
- 프로젝트 이름: `CX`

## 실행 방법

1. Unreal Engine 5.6.1과 C++ 개발 환경이 설치되어 있는지 확인합니다.
2. `CX.uproject`를 열고, 빌드가 필요하다는 안내가 나오면 빌드합니다.
3. 기본으로 열리는 메인 메뉴에서 **Play**를 누릅니다.
4. 닉네임과 차량 색상을 선택한 뒤 **게임 만들기**로 호스트를 시작하거나, 서버 주소를 입력하고 **서버 접속**을 선택합니다.

경기장만 확인하려면 `Content/Maps/L_WonMiningYard.umap`을 열어 실행할 수 있습니다. 에디터에서 멀티플레이를 확인할 때는 해당 맵의 Play 설정에서 플레이어 수를 2명으로, 네트워크 모드를 Listen Server로 설정합니다. 다른 PC에서 접속하려면 네트워크 환경에 맞는 주소와 연결 설정이 필요합니다.

## 게임 진행

1. 플레이어가 입장하면 준비 시간이 시작되고, 출발 전 화면 중앙에 **3 → 2 → 1 → GO!**가 표시됩니다.
2. 경기장 곳곳에 생성되는 원화와 속도 아이템을 획득합니다.
3. 다른 차량을 공격해 원화를 빼앗거나 지뢰로 주행을 방해합니다.
4. 제한 시간이 끝나면 최종 원화를 비교해 승패를 결정합니다. 최고 점수가 같으면 공동 우승입니다.

## 주요 기능

### 필수 기능

- 차량 주행과 멀티플레이 채팅
- 원화와 속도 아이템 획득 및 일정 시간 후 재생성
- 전방 공격으로 상대 차량의 원화 5개 이전
- 서버에서 경기 상태와 시간을 관리하고 경기 종료 시 결과 표시
- 개인 원화와 속도 정보 복제, 종료 후 최종 점수 공유

### 도전 기능

- **바퀴 피격:** 바퀴 명중 시 최고 속도가 한 번에 20km/h씩 감소하며 최대 80km/h까지 누적됩니다. 감소한 속도는 초당 5km/h씩 회복됩니다. 피해자의 원화가 5개 미만이면 원화 이전과 바퀴 패널티가 적용되지 않습니다.
- **지뢰:** F키로 차량 뒤에 설치합니다. 설치 간격은 3초이며, 밟은 차량은 2초 동안 가속할 수 없습니다. 설치한 플레이어의 차량도 영향을 받을 수 있습니다.
- **경기 상태에 따른 입력 제한:** 경기 대기와 종료 중에는 주행·공격·지뢰 설치 등을 제한합니다.

### 추가 기능

- **플레이어 설정:** 닉네임과 차량 색상 6가지 중 하나를 선택하고 로컬에 저장합니다. 닉네임은 이름표·채팅·결과창에 사용되며, 차량 색상은 다른 플레이어에게도 표시됩니다.
- **메뉴와 옵션:** 게임 생성·서버 접속, 음량, 해상도, 화면 모드, 그래픽 품질 설정을 지원합니다. 경기 중 옵션을 열어도 경기는 계속 진행됩니다.
- **레이싱 HUD:** 속도와 기어, 남은 시간, 원화, 지뢰 재사용 시간, 주행 상태를 표시합니다.
- **결과와 재시작:** 경기 종료 후 순위와 승패를 보여주며, 호스트가 다시 경기를 시작할 수 있습니다.
- **차량 복귀:** R키로 차량을 안전한 위치에 바로 세웁니다. 정지한 채 뒤집힌 상태가 지속되면 약 4초 후 자동 복귀합니다.
- **전투 피드백:** 명중 시 조준점에 표시를 보여주고, 바퀴 명중은 빨간 X와 CRITICAL로 구분합니다. 피격과 지뢰 폭발에는 불꽃·연기와 차량 물리 반응을 적용했습니다.

## 경기장

채석장을 콘셉트로 약 180m × 180m 규모의 경기장을 구성했습니다. 외곽 순환도로와 중앙 십자도로를 따라 네 개의 작업 구역이 배치되어 있으며, 컨테이너·크레인·굴착기·컨베이어·골재 더미·사일로와 바위로 공간을 채웠습니다. 출발 지점 3개, 원화 스포너 24개, 속도 아이템 스포너 4개를 배치했습니다.

메인 메뉴의 배경은 게임의 차량과 채석장 분위기를 참고한 콘셉트 이미지입니다.

## 프로젝트 구성

```text
CX/
├─ CX.uproject       언리얼 프로젝트
├─ Source/           게임 로직과 UI C++ 코드
├─ Content/          맵, 블루프린트, 재질과 게임 에셋
├─ Config/           프로젝트 및 입력 설정
├─ CH4_Assets/       사용한 에셋 자료
└─ Docs/             외부 에셋 출처와 라이선스 정보
```

프로젝트를 옮길 때는 `CX.uproject`, `Source`, `Content`, `Config`를 함께 보관합니다. 제작 도중 사용한 별도의 Python 스크립트는 게임 실행에 필요하지 않습니다.
