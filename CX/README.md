# CX — 분노의 질주: 원화 채굴

Unreal Engine 5.6.1 / C++ / Visual Studio 2022.

## 실행

`CX.uproject`를 열면 `Content/Maps/L_MainMenu.umap` 메뉴 맵이 열린다. Play 후 **게임 만들기**를 누르면 채굴 야적장을 리슨 서버로 시작한다. **서버 접속**은 서버 주소를 입력해 연결한다. 별도 PC 및 인터넷 연결에는 해당 환경에 맞는 네트워크 설정이 필요하다.

경기장만 바로 확인하려면 `Content/Maps/L_WonMiningYard.umap`을 연다. 두 명을 확인하려면 이 경기장 맵에서 Play 설정의 플레이어 수를 2명, 네트워크 모드를 Listen Server로 설정한다.

## 맵

180×180m 경기장, 외곽 순환도로, 중앙 십자도로, 컨테이너 야적장 네 곳, 크레인·사일로·광석·바위·안전벽을 배치했다. 시작 지점 3개와 원화 스포너 24개, 속도 버프 스포너 4개가 있다. 아이템 재생성 간격은 2초다.

컨테이너·크레인·방호벽·바위는 Fab에서 받은 모델을 Unreal Engine 5.6.1로 가져와 적용했다. 도로·콘크리트 표면은 현재 제작 재질을 사용한다.

## 화면과 조향

메인메뉴는 현재 게임의 스포츠카·컨테이너·크레인·사일로·바위 구성을 참고한 석양 콘셉트 일러스트다. 실제 플레이 화면을 캡처한 배경이 아니다. 이미지는 `Content/WonMining/UI/T_MainMenuSunset.uasset`에 있으며 제목·버튼·서버 주소는 실제 UI다. 경기장에도 낮은 태양, 따뜻한 빛과 긴 그림자를 적용하고 그늘 가시성을 위한 보조광을 사용했다.

앞바퀴 최대 조향각은 40도에서 52도로 조정했다. 스포츠카와 오프로드 차량에 함께 적용되며 저속·중속에서 조향량이 덜 줄어들도록 곡선을 조정하고, 좌우 입력 반응과 앞바퀴 접지력을 높였다. 고속의 조향 감소는 유지한다.

## 포함 기능

차량 주행, Enter 채팅, 원화와 최고속도 보너스의 서버 처리 및 소유자 복제, 공격으로 원화 5개 이전, 원화·속도 아이템 수집과 재생성, Waiting/Playing/Finished 상태와 남은 시간, 승리·패배·공동승리 표시.

## 도전 기능

- 좌클릭 공격은 서버에서 앞 범퍼의 라인 트레이스를 수행하고 `ApplyPointDamage`로 맞은 부위를 전달한다. 바퀴 Bone을 맞히면 원화 5개 이전과 함께 속도 패널티가 적용된다. 원화가 5개 미만이면 이전과 패널티를 적용하지 않는다.
- 바퀴 피해는 1회 -20km/h, 누적 하한 -80km/h다. 초당 5km/h씩 0까지 회복하며, 기존에 획득한 속도 보너스는 유지된다.
- **F키**로 차량 뒤에 지뢰를 설치한다. 설치 간격은 3초, 작동 준비는 0.25초, 유지 시간은 30초다. 설치한 차량이 Owner이며 설치자도 다시 밟으면 영향을 받는다.
- 지뢰를 밟으면 폭발과 함께 2초 동안 가속 입력이 차단된다. 남은 고장 시간은 개인 HUD에 표시된다.
- **Playing**에서만 가속·조향·공격·지뢰 설치·차량 리셋을 허용한다. **Waiting/Finished**에서는 가속·조향을 0으로 유지하고 핸드브레이크를 잠근다. Playing 전환 시 상태용 잠금은 자동 해제된다.

## 추가 기능

- 메인메뉴에서 닉네임(최대 16자)과 차량 색상 6가지를 선택한다. 닉네임과 색상, 음량은 이 프로젝트의 로컬 저장 파일에 보관된다. 선택한 닉네임은 차량 이름표·채팅·결과창에 사용되고 색상은 다른 플레이어에게도 전달된다. 메뉴의 색상 테두리는 선택 색상을 보여주며 배경 일러스트의 차량 도색은 바뀌지 않는다.
- 옵션에서 전체/효과음 음량, 해상도, 창/테두리 없는 전체 화면/전체 화면, 그래픽 품질을 적용하고 저장한다. 효과음 음량은 아이템 획득과 지뢰 폭발에 적용되고 전체 음량은 차량 소리를 포함한 게임 전체 음량에 적용된다.
- HUD에는 개인 코인, 남은 시간, 최고 속도, 바퀴 손상, 가속 불가 시간, 지뢰 재사용 시간이 표시된다. 경기 중 상대 코인은 공개하지 않고 종료 시 최종 점수표를 공유한다.
- 결과창에 승리·패배·공동 우승과 최종 코인을 표시한다. 호스트는 다시 경기하기로 전체 경기를 초기화하고 닉네임·도색은 유지한다. 참가자는 메인메뉴로 나갈 수 있다. 호스트가 나가면 해당 서버 연결은 종료된다.
- **Tab**으로 경기 중 옵션을 열고 **Esc** 또는 돌아가기로 닫는다. 옵션을 연 차량은 입력이 잠기지만 멀티플레이 경기는 계속된다.
- **Enter**로 채팅 입력을 열고 다시 **Enter**로 전송한다. **Esc**로 입력을 취소한다. 채팅 입력 중에는 차량 조작을 잠그고 전송/취소 후 복귀한다.
- 서버 연결에 실패하거나 호스트 연결이 끊어지면 메인메뉴에 안내를 표시한다.

프로젝트를 옮길 때 `CX.uproject`, `Source`, `Config`, `Content`를 함께 보관한다. 제작에 사용한 외부 도구나 Python 스크립트는 프로젝트 실행에 필요하지 않다.

## 출발 연출과 차량 복귀

기존 경기 준비 시간의 마지막 3초에 화면 중앙으로 **3 → 2 → 1 → GO!**를 표시한다. 시작 시각은 서버 시간을 기준으로 동기화한다. 경기 HUD와 채팅에는 검은 바탕 상자를 표시하지 않고 글자 그림자·외곽선으로 구분한다.

**R키**로 주변의 비어 있는 지면에 차량을 바로 세운다. 벽·차량·높은 장애물 위를 피하고 필요하면 마지막 정상 주행 위치나 출발 지점을 찾는다. 정지한 채 뒤집혀 있으면 **4초 후 자동 복귀**하며 남은 시간과 R키 안내를 HUD에 표시한다. 서버가 복귀를 결정하고 운전자 클라이언트에도 같은 위치를 적용한다. 복귀 재사용 제한은 2초다.

맵은 석양색 조명, 메뉴 이미지에서 분위기를 맞춘 파노라마 하늘, 따뜻한 바위와 콘크리트, 짙은 아스팔트로 보완했다. 주행로·출발 지점·아이템 배치는 유지했다.
