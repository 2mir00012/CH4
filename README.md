# 분노의 질주: 원화 채굴

석양이 내려앉은 채석장에서 차량을 운전하며 원화를 모으고 상대 차량과 경쟁하는 멀티플레이 게임입니다.

## 게임 목표

경기장에 흩어진 원화를 수집하고 상대의 공격을 피하면서 제한 시간 안에 가장 많은 원화를 모읍니다. 차량 공격과 지뢰를 활용해 상대를 견제할 수 있습니다.

## 주요 기능

- **차량 주행과 아이템:** 경기장을 달리며 원화와 최고 속도 증가 아이템을 획득합니다.
- **차량 전투:** 전방 공격으로 상대의 원화를 빼앗고, 바퀴에 명중하면 일시적으로 속도를 감소시킵니다.
- **지뢰:** 차량 뒤에 설치한 지뢰가 폭발하면 일정 시간 가속이 제한됩니다.
- **경기 진행:** 준비 시간과 출발 카운트다운을 거쳐 경기가 시작되며 종료 시 점수와 승패를 확인합니다.
- **플레이어 설정:** 닉네임과 차량 색상을 선택하고 음량·화면·그래픽 설정을 변경할 수 있습니다.
- **차량 복귀:** 차량이 뒤집히면 직접 복귀하거나 일정 시간 후 자동으로 바로 세울 수 있습니다.
- **경기장과 UI:** 채석장 분위기의 맵과 메인 메뉴, HUD, 옵션, 채팅 및 결과 화면을 제공합니다.

## 핵심 구현 방식

서버가 아이템 획득, 공격과 지뢰 판정, 경기 시간 및 결과를 관리합니다. RPC와 상태 복제를 이용해 플레이어에게 필요한 정보를 전달하고, UMG로 경기 상황과 개인 설정을 표시합니다. 차량 주행과 복귀에는 Chaos Vehicles와 물리 처리를 사용합니다.

## 기술 스택

- Unreal Engine 5.6.1, C++, Blueprint, UMG
- Visual Studio 2022, Chaos Vehicles
- Listen Server, RPC, 상태 복제

## 실행 방법

1. Unreal Engine 5.6.1과 Visual Studio 2022의 C++ 게임 개발 도구를 준비합니다.
2. [CX.uproject](CX.uproject)를 열고 필요한 경우 빌드합니다.
3. 메인 메뉴에서 Play 후 **게임 만들기**를 선택하거나 서버 주소를 입력해 접속합니다.
4. 에디터에서 두 플레이어를 시험하려면 `Content/Maps/L_WonMiningYard`를 열고 플레이어 수를 2명, 네트워크 모드를 Listen Server로 설정합니다.
